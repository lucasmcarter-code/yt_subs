This page reads your subscription list from YouTube and shows the newest uploads, nothing else. Everything you enter stays in this browser.

How to get an API key (one time, free)
  1. Go to console.cloud.google.com and create a project.
  2. Open APIs & Services, then Library, and enable YouTube Data API v3.
  3. Open Credentials, choose Create credentials, then API key.
  4. Restrict the key to YouTube Data API v3, and to this page's web address under Website restrictions.
Works when your subscriptions are public: in YouTube, open Settings, then Privacy, and turn off "Keep all my subscriptions private".
